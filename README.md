# Nathaly Chamorro

Landing comercial para Nathaly Chamorro — Contabilidad, Impuestos y Finanzas.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Preparado para Vercel

## Desarrollo

```bash
npm install
npm run dev
```

## Objetivo

Sitio institucional y comercial orientado a SEO y captación de consultas, con foco inicial en Limpio y crecimiento hacia búsquedas de servicios contables en Paraguay.

Pendiente para producción: número de WhatsApp, fotografías reales, redes sociales, ubicación, horarios y dominio definitivo.
